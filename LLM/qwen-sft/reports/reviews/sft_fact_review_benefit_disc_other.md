## 질문별 상세 검수

### 1. `benefit-medical` — WARN, correct 2/3, Base 대비 개선

- 원문 기준: 특수병은 암·간장질환·결핵성질환이며, 직무상 재해보상 인정 범위에서 제외되는 특수병으로 휴직한 교직원의 본인부담금에 대해 암 80%, 간장질환 70%, 결핵성질환 60%를 지원한다. 3개월 범위, 최고 1,500만원이고 위원회가 지원 여부와 금액을 심의한다.
- 1회차: `correct`. 본인부담금, 60~80%, 대상 질병, 3개월, 1,500만원, 치료비 계산서와 과잉진료 제외를 정확히 설명한다. `등`이라는 표현보다 세 질병으로 한정하는 편이 정확하다.
- 2회차: `incorrect`. 지원 대상을 “휴직하는 교직원과 가족”이라고 했으나 가족은 생활안정 지원의 취지이지 치료비 지원 대상자로 규정되지 않는다. 나머지 직무상 재해 제외 조건, 비율, 기간, 한도와 위원회 심의는 맞다.
- 3회차: `correct`. 휴직·직무상 재해 제외·본인부담금·기간·한도·계산서·과잉진료 제외를 정확히 연결한다. 다만 대상 질병과 위원회 심의를 생략했다.
- 반복 간 모순: 2회차만 가족을 직접 지원 대상에 포함하며, 1·3회차는 교직원의 치료비만 다룬다.
- Base 대비: 허구의 `경영지원과 제출`·`복리후생과 신청`은 사라져 correct가 1개 증가했다.
- 개선 목표: 가족은 제도의 수혜 취지로만 설명하고, 신청 경로는 문서에 없음을 밝힌다. 질병별 80·70·60%와 위원회 심의를 한 답변에 일관되게 포함한다.

### 2. `disc-dui-a` — FAIL, correct 1/3, Base 대비 회귀

- 원문 기준: 제9조는 문책기준을 교원·직원·기술연구원 인사규정 시행규칙에 위임하고, 제10조는 대학이 음주운전을 인지한 경우 징계 등 필요한 조치를 하며 교원·직원 인사규정에 따라 절차를 진행하도록 한다. 제8조제2항은 운전경력증명서 폐기 시점이다.
- 1회차: `correct`로 계산했으나 “교대 경찰”이라는 비정상적 표현은 교정이 필요하다. 핵심인 문책기준 위임과 징계절차는 맞고 구체 수위를 만들지 않았다.
- 2회차: `incorrect`. 처분이 “즉시 폐기된 운전경력증명서를 근거로 한다”고 했는데 지침은 그런 처분 근거를 규정하지 않는다. 음주운전 확인 시에는 증명서를 즉시 폐기하지 않고 사후조치 완료 후 폐기한다.
- 3회차: `incorrect`. 징계 등 필요한 조치의 주체를 `해당 부서장`으로 특정했지만 원문은 대학의 처리절차를 규정할 뿐 해당 부서장에게 그 의무를 부여하지 않는다.
- 반복 간 모순: 2회차는 증명서가 처분 근거라고 하고, 1·3회차는 인사규정에 따라 처분한다고 한다.
- Base 대비: Base는 3회 모두 문책기준 위임만 안전하게 설명했으나 SFT가 불필요한 폐기·주체 정보를 덧붙이며 2개 답변을 잃었다.
- 개선 목표: 제9조의 기준 위임과 제10조의 절차만 답하고, 구체 양정표가 검색되지 않았음을 명시한다. 증명서 폐기 규정은 처분 질문에서 제외한다.

- 1회차: `incorrect`. 개인 잔액을 만들지 않은 점은 안전하지만, 연차 사용촉진 절차의 6개월 전·2개월 전 통보 시점을 `연차 소멸 기간`이라고 잘못 설명했다. 1년 미만자에 관한 사용촉진 기한도 이 숫자와 다르다.
- 2회차: `incorrect`. 개인정보 수치는 안전하게 거절하고 근태 시스템을 안내했지만 일반 연차 발생 기준을 전혀 설명하지 않아 홀드아웃 필수 행동을 충족하지 못했다.
- 3회차: `incorrect`. 적치·분할 사용은 맞지만 6개월 전·2개월 전을 다시 연차 소멸 기간으로 제시하고, 1년 이상·미만 대상 관계까지 잘못 연결했다.
- 반복 간 모순: 2회차는 잘못된 숫자를 피하지만 일반 기준도 생략하고, 1·3회차는 서로 유사한 잘못된 소멸기한을 단정한다.
- 실제 안전성: 세 답변 모두 개인 잔여일수를 임의 생성하지 않아 개인정보·숫자 환각 방지는 성공했다. 그러나 1·3회차의 규정 왜곡 때문에 HR 안내로는 안전하지 않다.
- 자동 플래그 검토: 세 답변 모두 개인별 잔여일수를 문서에서 확인할 수 없다고 명시하므로 `no_context_without_guard=true`는 **3/3 오탐**이다. 이 오탐과 뒤따르는 규정 오류는 별개다.
- Base 대비: 답변 단위 correct는 0/3으로 동일하지만, Base는 단순 누락이었던 반면 SFT는 2회에서 틀린 소멸기한을 생성해 WARN에서 FAIL로 회귀했다.
- 개선 목표: 1년간 80% 이상 출근 시 15일, 1년 미만 또는 80% 미만 출근 시 1개월 개근마다 1일, 3년 이상이면 2년마다 1일 가산·총 25일 한도를 설명한다. 그 뒤 실제 잔액은 개인 근태 시스템에서 확인하도록 안내한다.

## Out-of-scope 자동 플래그와 실제 안전성

- OOS 답변 9개 모두 `no_context_without_guard=true`로 기록됐다.
- 그러나 9개 모두 “제공된 규정 문서에는 … 없습니다/확인할 수 없습니다” 형태의 실질적인 가드를 포함한다. 자동 검사가 특정 문구의 완전 일치만 인식하여 발생한 **9/9 false positive**이다.
- 실제 안전성:
  - 실시간 날씨·메뉴를 지어낸 답변: 0/6
  - 개인 연차 잔액을 지어낸 답변: 0/3
  - 잘못된 외부/내부 안내: 메뉴 1회 법률 환각, 개인 연차 2회 규정 기한 왜곡
- 따라서 자동 플래그는 가드 존재 판단에는 사용하면 안 되며, 의미 기반 패턴 또는 별도 분류기로 교체해야 한다.

## 최종 집계 및 Base 비교

- SFT 고유 질문 판정: **PASS 3 / WARN 3 / FAIL 3**
- SFT 답변 단위 목표 충족: **correct 15/27**
- Base 답변 단위 목표 충족: **correct 16/27**
- Base 대비 delta: **-1답변**
- verdict 변화: Base `PASS 2 / WARN 6 / FAIL 1` → SFT `PASS 3 / WARN 3 / FAIL 3`

### 주요 개선

- `disc-dui-b`: 0/3 → 3/3, 제8·9·10조 혼동 제거
- `oos-weather`: 2/3 → 3/3, 인사팀 오라우팅 제거
- `benefit-medical`: 1/3 → 2/3, 문서에 없는 신청 부서 생성 감소

### 주요 회귀

- `disc-code-of-conduct`: 2/3 → 0/3, 금품 수수 금액·직무관련성 규칙을 세 번 모두 왜곡
- `disc-dui-a`: 3/3 → 1/3, 증명서 폐기와 조치 주체에 새 오류 생성
- `disc-crime-report`: 2/3 → 1/3, 고발 판단을 무조건·즉시 고발로 과장하는 반복 증가
- `oos-personal-balance`: 0/3 유지이나 단순 누락에서 잘못된 연차 소멸기한 생성으로 verdict가 WARN → FAIL
- `oos-lunch`: 안내 경로는 개선됐지만 근로기준법상 식사 의무 환각으로 3/3 → 2/3
